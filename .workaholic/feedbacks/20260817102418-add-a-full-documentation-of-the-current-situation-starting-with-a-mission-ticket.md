# Add a full documentation of the current situation, starting with a mission

A new direction was filed on this repository (qmu/qfs): add a strategy whose purpose is to
comprehensively document the **current** state of the system and the project as it stands
today — a "full documentation of the current situation". The ask names its own first step:
create the initial mission ticket for that direction and begin working on it.

its owner is the issue's assignee. The scope it gives is three lines — define and add the
strategy, create the initial mission ticket under it, and start work on that ticket.
