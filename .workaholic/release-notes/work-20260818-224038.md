# qmu/plgg is public, not private, and the upstream issue was already filed etc

## Summary

The npx smoke's bun exemption is retired. bun fixed the parse defect in 1.3.13 against an
unchanged `plgg-md@0.0.3`, so the wait was never on the package. The gate now covers node, bun
and deno with nothing exempted, and CI installs all three.

## Key Changes

- `qmu/plgg` is a **public** repository, not the private one three blocked entries assumed, and
  the upstream issue was already filed as [qmu/plgg#131](https://github.com/qmu/plgg/issues/131).
- The parse defect was **bun's**, fixed in **bun 1.3.13** — measured per version with official
  release binaries against an unchanged `plgg-md@0.0.3`.
- The npx smoke's exemption is gone; `check-all.sh` passes with node, bun and deno all covered
  and no `NOT COVERED` line, in CI as well as locally.

## Changes

### Added
- `viewer-check-all` installs bun and deno alongside Node 24, so a green badge attests to the
  whole runtime matrix rather than to node alone.

### Changed
- `smoke-npx.sh` replaces the bun exemption with the measured version floor: an older bun now
  **fails** the gate by name with the upgrade instruction, instead of being reported
  `NOT COVERED`, and bun counts in `RAN` again.
- `packages/qfs-viewer/README.md` and `docs/guide/repository.md` retire the bun-is-broken caveat
  and keep the history as history.

### Removed
- The dated bun exemption in `packages/qfs-viewer/scripts/smoke-npx.sh`, together with its
  2026-11-17 revisit backstop.
