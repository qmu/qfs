## 1. Overview

Blueprint §13.1 **G9** promised that PREVIEW *additionally refuses a malformed reference with no
I/O*. The implementation declined that clause on purpose and never performed the check, so the
design document described a refusal the binary does not make. This branch rules the deviation
**confirmed** and corrects the clause; no behaviour changes.

**Highlights:**

1. G9's timing bullet now states the truth — PREVIEW performs no I/O, so it resolves nothing and refuses nothing.
2. The reason the check was declined is recorded beside the clause, so it is not re-proposed blind.
3. The already-shipped test that pins the true property is named from the blueprint, closing the document/binary loop.

## 2. Motivation

A design document that promises a refusal the binary does not perform is worse than silence: it is
the reference a reader trusts. The gap was recorded as a moderate concern out of the G9
implementation on 2026-08-04 and sat open until this ticket. The truthful property — that PREVIEW
performs **zero** I/O for a name-addressed CALL, and that an unresolvable or ambiguous reference is
a structured refusal at COMMIT before the effect leg is constructed — was asserted only in a test,
which a reader of §13.1 never sees.

## 3. Changes

### 3-1. The blueprint promises a preview-time malformed-reference refusal the implementation deliberately declined ([ce34ecd](https://github.com/qmu/qfs/commit/ce34ecd))

Ruled **Option A — confirm the deviation**, the ticket's expected reading, and rewrote G9's `Time`

## 4. Outcome

The document and the binary now agree, and each points at the other: §13.1 G9 names
`preview_of_a_name_addressed_call_performs_no_io_at_all`, and that test's comment names the amended
clause. The open concern `the-preview-time-malformed-reference-refusal` is superseded as resolved.
qfs `0.0.104`.

## 6. Successful Development Patterns

- Ruling a documented-versus-shipped gap by reading the *reason* the code declined the promise, rather than by implementing the promise: the decline was an application of 「推測するな、宣言して拒否せよ」, which made the document the thing to fix.
