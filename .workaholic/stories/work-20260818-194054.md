## 2. Motivation

Removing the custom-domain routes from `docs/wrangler.toml` was the change that made the CI token narrowable, and it updated the deployment record's Credentials table in the same commit to state the account-only scope a routeless deploy needs. Read on its own afterwards, that table describes a token nobody has minted: `CLOUDFLARE_API_TOKEN` still holds the original `Zone → Workers Routes → Edit` on `qmu.co.jp`. A record that documents an intended bound as if it were the live one is the failure mode the record exists to prevent — anyone judging the deploy path's blast radius would read the narrow scope and stop looking.
