## 1. Overview

`GET /rooms` returns five fields the shipped `chatwork/room` type did not name — `sticky`, `icon_path`, `mytask_num`, `file_num`, `task_num` — so the `OF` projection dropped them before any row left the view and no query could reach them. This names all five, adds the recipe the most valuable one enables, and regenerates the skill.

**Highlights:**

1. `chatwork/room` now names every field the endpoint delivers, so all five are queryable.
2. A new cookbook recipe answers "which rooms are waiting on me" over `mytask_num` — previously unanswerable.
3. No view change was needed: `/chatwork/rooms` has no explicit `SELECT`, so the widened `OF` type is what shapes its output.

## 2. Motivation

A declared driver's type is not a convenient subset — it is the projection. A column the type omits is a column no caller can reach, because the `OF` contract drops it before the rows leave the view. So five fields Chatwork actually delivers were silently unreachable, `mytask_num` (the count behind "which rooms are waiting on me") among them. The fix was salvaged from the closed PR #65, whose reasoning for carrying every field is the part worth keeping.

## 3. Changes

### 3-1. Name every chatwork room field the API returns ([c2f0341](https://github.com/qmu/qfs/commit/c2f0341))

Adds `sticky`/`icon_path` (metadata) and `mytask_num`/`file_num`/`task_num` (counts) to `CREATE TYPE chatwork/room` in the shipped asset, with a comment recording why every delivered field must be named; adds a "rooms waiting on me" recipe to the chatwork cookbook; regenerates the skill and bumps the four plugin `version` fields (0.21.1 → 0.21.2) since the taught surface changed.

## 4. Outcome

The widened 13-column type installs and commits, and the new recipe parses and plans. `#65`'s view restyle was deliberately not ported (the `SELECT` form from #46 stays under the cookbook ratchet). The cookbook ratchet, `gen-skills --check`, `gen-docs --check`, `cargo test --workspace` (149 binaries, 0 failed), `clippy -D warnings`, and `fmt --check` all pass.
